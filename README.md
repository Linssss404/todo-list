# Linsssside

一个只在这台电脑上跑的个人生活助手：**待办 / 记账 / 日程 / 灵感** 四个模块，数据全部落在本地的一个 SQLite 文件里。

---

## 怎么打开

双击 **`启动 Linsssside.cmd`**。想放到桌面，双击一次 `创建桌面快捷方式.cmd`。

或者安装 `release\Linsssside-Setup-1.0.0.exe`（安装版会在开始菜单和桌面建快捷方式）；想免安装就用 `release\Linsssside-Portable-1.0.0.exe`。

关掉窗口不会退出，应用会缩到右下角托盘里继续盯着时间，到点弹 Windows 通知。要彻底退出就右键托盘图标 → 退出。

**随手记**：任意时候按 `Ctrl + Alt + Space`，弹出一个小窗，写一句话回车就存下——Tab 切换存成「灵感 / 待办 / 支出」。支出写成 `18 早餐` 会自动解析金额。

## 数据在哪

```
data/life.db              你的全部数据（标准 SQLite，可用 DB Browser for SQLite 打开）
data/attachments/         笔记里的图片
data/exports/<时间>/      一键导出的快照（全部数据 JSON + 账单 CSV + 待办 CSV）
```

备份就是把整个 `data` 文件夹拷走；换电脑连着 `data` 一起搬。数据不会离开这台电脑，没有任何网络请求。

## 四个模块

**仪表盘**
- 今天的一句话状态、今日待办、快速添加
- **给今天起个名字**：点标题就地输入，回车保存（比如「自信绽放日」）
- 本月支出与预算进度、接下来 7 天（日程 + 待办截止）、最近三条灵感

**待办**
- 多清单（默认：收件箱 / 工作 / 生活），双击清单名改名，删清单时里面的待办回到收件箱
- 优先级（高 / 中 / 低）、截止日期与时间、全天、备注
- 重复（每天 / 每周 / 每月 / 每年，可设间隔），完成一次自动生成下一次
- 子任务（父任务完成时子任务一起完成）、拖拽排序
- 视图：全部 / 今天 / 即将 / 已完成；右侧抽屉就地编辑，改动自动保存

**记账**
- 一句「金额 + 分类 + 备注」就能记一笔，收支双向
- 自定义分类：emoji + 颜色，可增删改；删分类时账目变成「未分类」而不是被删掉
- 月度总预算 + 进度条，超支会变红提示
- 分类占比环图、近 6 个月收支柱图
- 按月筛选、按分类筛、按收支筛；单笔可改金额/分类/日期/商家/备注/标签

**日程**
- 月历 / 周视图时间轴 / 列表流三种看法
- 全天与带时间段的事件、重复日程、提前 5 分钟 ~ 1 天提醒
- **待办的截止时间自动出现在日历上**，在日历里直接打勾就能完成
- 每天的名字显示在日历格子里；点某天打开当天面板，可直接加一件事

**灵感**
- Markdown 编写 + 预览（标题、粗体、列表、引用、代码、链接、图片）
- 标签、全文搜索、置顶、归档
- 图片直接粘贴进正文，存到 `data/attachments/`
- 一键转成待办

**全局**
- `Ctrl + K`：四个模块一起搜（待办、日程、账单、笔记、每天的名字）
- 浅色 / 深色切换、启动密码锁、一键导出

## 只想先看界面

双击 **`查看界面预览.cmd`**，用默认浏览器打开 `preview/index.html`。

里面有 10 页静态预览（仪表盘 / 待办 / 待办详情 / 记账 / 日程 / 灵感 / 快速记录窗，浅色与深色）。它们是把 React 真实渲染结果导出的 HTML，和桌面版共用同一份 CSS——看到的排版、颜色、间距就是应用里的样子，只是点按钮不会动。

重新生成：`pnpm preview`。

## 给开发者的部分

```bash
pnpm install          # 装依赖（Electron 会下载约 100MB 运行时）
pnpm build            # 用 Rollup + Babel 打包渲染进程到 dist/
pnpm start            # 构建后启动
pnpm test             # 后端数据库测试 + jsdom 界面冒烟测试
pnpm preview          # 重新生成静态预览页
pnpm dist             # 打 Windows 安装包与便携版
```

目录：

```
electron/              主进程
  main.js              窗口、托盘、单实例、全局快捷键、到期提醒轮询
  preload.js           只暴露 api.call 一个通道
  db.js                sql.js（SQLite WASM）+ 建表 + 默认数据 + 原子落盘
  ipc.js               通用接口：清单 / 待办 / 日命名 / 设置 / 首页 / 搜索 / 导出 / 密码
  modules/
    money.js           记账：分类、流水、月度汇总与趋势、预算
    calendar.js        日程：事件 CRUD、重复展开、与待办合并成 agenda
    notes.js           灵感：笔记、标签、附件、转待办、快速记录
  time.js              本地时间与重复规则
src/                   渲染进程（React）
  pages/               Dashboard / Todos / Money / Calendar / Notes
  components/          TopNav / DayTitle / TodoRow / TodoDrawer / SearchPalette / SettingsModal / LockScreen
  lib/                 dates / money / markdown
  quick.jsx            快速记录小窗
tools/
  build.mjs            Rollup 构建脚本（两个入口：主窗口 + 快记窗）
  db-test.mjs          后端断言：待办/记账/日程/灵感/密码/导出/落盘/重开
  smoke.mjs            界面断言：jsdom 里真实挂载、点击、切页
  mock-api.mjs         测试与预览共用的假后端
  preview.mjs          把真实渲染结果导出成静态 HTML
```

几个设计上的约束：

- 数据层用 `sql.js`（WASM），不需要在用户机器上编译原生模块；产出的仍是标准 `.db`。
- 写盘是「先写临时文件再改名」，断电不会写坏数据库。
- 金额一律以「分」存整数，避免浮点误差。
- 渲染进程拿不到 Node 能力，只能通过 `api:call` 一个通道做事。

# Linsssside

一个只在这台电脑上跑的个人生活助手：**待办 / 记账 / 日程 / 灵感** 四个模块，数据全部落在本地的一个 SQLite 文件里。

> 当前进度：**第 1 阶段**——工程骨架 + 待办模块 + 每日命名。记账 / 日程 / 灵感三个页面已占位，等确认风格后接着写。

---

## 怎么打开

双击 **`启动 Linsssside.cmd`**。想放到桌面，双击一次 `创建桌面快捷方式.cmd` 即可。

关掉窗口不会退出，应用会缩到右下角托盘里继续帮你盯着时间，到点弹 Windows 通知。要彻底退出就右键托盘图标 → 退出。

## 只想先看界面

双击 **`查看界面预览.cmd`**，会用默认浏览器打开 `preview/index.html`。

里面有 6 页静态预览（仪表盘/待办/抽屉/记账占位，浅色与深色各一套）。它们是把 React 真实渲染结果导出的 HTML，和桌面版共用同一份 CSS，所以看到的排版、颜色、间距就是应用里的样子——只是点按钮不会动。

重新生成：`pnpm preview`。

## 数据在哪

```
data/life.db          你的全部数据（标准 SQLite，可用 DB Browser for SQLite 打开）
data/exports/...      每次「一键导出」生成的快照（JSON + 账单 CSV + 待办 CSV）
```

- 备份就是把整个 `data` 文件夹拷走。
- 换电脑把 `data` 一起带过去就行。
- 数据不会离开这台电脑，没有网络请求。

## 已经能用的

**仪表盘**
- 今天的一句话状态、今日待办、快速添加
- **给今天起个名字**：点标题就地输入，回车保存（比如「自信绽放日」）
- 其余三张卡是下一阶段的占位

**待办**
- 多清单（默认：收件箱 / 工作 / 生活），双击清单名可改名，删清单时里面的待办会回到收件箱
- 优先级（高 / 中 / 低）、截止日期与时间、全天、备注
- 重复（每天 / 每周 / 每月 / 每年，可设间隔），完成一次自动生成下一次
- 子任务（父任务完成时子任务一起完成）
- 拖拽排序
- 视图：全部 / 今天 / 即将 / 已完成
- 到点系统通知（应用在托盘里也照常提醒）
- 右侧抽屉就地编辑，改动自动保存，不用点保存按钮

**全局**
- `Ctrl + K`：跨模块搜索（待办、每天的名字）
- 浅色 / 深色切换
- 启动密码锁（设置里可开、可改、可关；忘记密码删掉 `data/life.db` 里的 settings 即可重置，数据不丢）
- 一键导出（`设置 → 数据 → 一键导出`）

## 给开发者的部分

```bash
pnpm install          # 装依赖（Electron 会下载约 100MB 运行时）
pnpm build            # 用 Rollup + Babel 打包渲染进程到 dist/
pnpm start            # 构建后启动
pnpm test             # 后端数据库测试 + jsdom 界面冒烟测试
pnpm dist             # 打 Windows 安装包（需要 NSIS，首次会下载）
```

目录：

```
electron/            主进程
  main.js            窗口、托盘、单实例、到期提醒轮询
  preload.js         只暴露 api.call 一个通道
  db.js              sql.js（SQLite WASM）+ 建表 + 原子落盘
  ipc.js             全部业务方法（清单/待办/日命名/设置/搜索/导出/密码）
  time.js            本地时间与重复规则
src/                 渲染进程（React）
  pages/             Dashboard / Todos / ComingSoon
  components/        TopNav / DayTitle / TodoRow / TodoDrawer / SearchPalette / SettingsModal / LockScreen
tools/
  build.mjs          Rollup 构建脚本
  db-test.mjs        后端断言（增删改、重复规则、锁定、导出、落盘、重开）
  smoke.mjs          界面断言（jsdom 里真实挂载并点击）
```

设计上的几个约束：

- 数据层用 `sql.js`（WASM），不需要在用户机器上编译原生模块；产出的仍是标准 `.db`。
- 写盘是「先写临时文件再改名」，不会因为断电写坏数据库。
- 渲染进程拿不到 Node 能力，只能通过 `api:call` 一个通道做事。
